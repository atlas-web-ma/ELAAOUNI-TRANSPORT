# ELAAOUNI-TRANSPORT 🚚

Site web vitrine pour société de transport et logistique au Maroc.

Site moderne et responsive pour présenter les services de transport.

### ✨ Fonctionnalités
- Page d'accueil avec bannière et présentation
- Galerie de véhicules (transport1.jpg à transport6.jpg)
- Section Services
- Design responsive
- Contact & Devis

### 🛠️ Technologies
- HTML5
- CSS3
- JavaScript

### 📁 Structure
- `index.html` - Page principale
- `style.css` - Styles
- `banner.jpg`, `logo.jpg` - Images de marque
- `transport1.jpg` - `transport6.jpg` - Flotte de véhicules

### 🚀 Voir le site
Ouvrir `index.html` dans le navigateur.
